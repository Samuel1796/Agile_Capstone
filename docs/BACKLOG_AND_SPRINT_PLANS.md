# Backlog & Sprint Plans (Summary)

This document summarizes the Product Backlog, refinement, and sprint plans for the Agile Capstone.

## Product Backlog (Refined)

- **US-1** Create user (id, name, email) — High — 2 pts — AC: create flow, validation, success/error messages  
- **US-2** List all users — High — 2 pts — AC: list with id/name/email, empty-list message  
- **US-3** Update user by id — High — 2 pts — AC: update by id, validation, confirmation/error  
- **US-4** Delete user by id — High — 2 pts — AC: delete by id, confirmation/error  
- **US-5** Health/status check — Medium — 1 pt — AC: health response (e.g. menu option)  
- **US-6** Basic logging — Medium — 1 pt — AC: log key actions and errors  

**Total:** 10 story points. **DoD:** See `docs/SPRINT0_PLANNING.md`.

## Sprint 1 Scope

- US-1 (Create), US-2 (List), US-4 (Delete) — minimum 2–3 stories.
- CI/CD with GitHub Actions; tests in pipeline; incremental Git commits.

## Sprint 2 Scope

- US-3 (Update), US-5 (Health), US-6 (Logging).
- Apply Sprint 1 retrospective improvements; add monitoring/logging.

Full details: `docs/SPRINT0_PLANNING.md`.
